The source code for **Ujjwal Pratap’s personal developer portfolio**, built to present his projects, technical interests, learning journey, and professional profile in one place. Ujjwal is a B.Tech Computer Science Engineering student at GLA University, Mathura, Uttar Pradesh, and CEO of AP Creative Studio.

## Portfolio overview

The website is designed to bring together:

- A personal introduction and education details
- Programming, web development, and data/AI skills
- Selected software and web application projects
- GitHub activity and LeetCode profile sections
- Certificates and resume resources
- LinkedIn and contact links

The content is data-driven, so profile details and project entries can be maintained separately from the page components.

## Technology stack

- **React 18** for the user interface
- **TypeScript** for typed application code
- **Vite** for development and production builds
- **GSAP** for interface animation
- **Lucide React** for icons
- **GitHub Actions** workflow configuration for deployment

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/Ujjwalpratap001/ujjwal-portfolio.git
cd ujjwal-portfolio
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```
